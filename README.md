# AI-асистент адвоката — етап 1 (MVP)

Telegram-бот приймає звернення клієнтів, а адвокат працює з ними **у веб-платформі**: бачить картку справи,
листування, затверджує відповіді. Telegram адвокату не потрібен.

Аналіз ТЗ і обґрунтування рішень: [`docs/feasibility-analysis.md`](docs/feasibility-analysis.md).

## Що вміє MVP

**Клієнт у Telegram** (кроки 1–7 ТЗ):
1. Привітання, згода на обробку даних, посилання «Як ми захищаємо ваші дані».
2. Терміновий фільтр (затримання, обшук, допит, суд ≤ 3 днів) → адвокату email, клієнту — телефон.
3. Верифікація: ПІБ + телефон (кнопкою «Поділитися номером»).
4. Перевірка конфліктів: друга сторона звіряється з базою клієнтів, клієнт — з опонентами інших справ.
   Якщо ПІБ збігся з кимось у базі, бот просить РНОКПП: повідомлення з кодом одразу видаляється з чату,
   код шифрується і ШІ його не бачить. За можливого конфлікту клієнт чує лише «заявка на розгляді».
5. Опитування: категорія → базові питання + питання категорії → до 2 раундів уточнень від ШІ.
6. Документи: перелік для категорії, інструкція сканування (Android/iPhone), фото/PDF, перевірка читабельності.
7. Підтвердження: «відповідь протягом 2 робочих днів» (7 — якщо Аналітик позначив справу складною).

На будь-якому кроці клієнт може написати «адвокат» — асистент замовкає, адвокату йде сповіщення.

**Адвокат у веб-платформі**: дашборд за статусами (термінові вгорі, прострочені червоним, цифри за тиждень),
чати з перехопленням і внутрішніми нотатками, картка справи від ШІ, рішення щодо конфлікту, редактор
відповіді з кнопкою «Затвердити й надіслати», клієнти з імпортом/експортом Excel, налаштування всіх текстів,
анкет і переліків документів без програміста, журнал дій.

**Захист даних**: вхід за паролем + кодом 2FA; РНОКПП/ЄДРПОУ зашифровані; паспорт, коди, телефони й номери
карток маскуються («***») до передачі в ШІ; вміст від клієнта ШІ читає як дані, а не команди; у листах
адвокату — лише номер звернення й посилання; кожен перегляд справи пишеться в журнал.

## Запуск на своєму комп'ютері

Потрібен **Python 3.11+** ([python.org](https://www.python.org/downloads/), на Windows поставте галочку
«Add Python to PATH»).

```bash
# 1. Завантажити код і встановити залежності
git clone https://github.com/Fabicool/lawtgbot.git
cd lawtgbot
python -m venv .venv
# Windows:  .venv\Scripts\activate      macOS/Linux:  source .venv/bin/activate
pip install -e .

# 2. Налаштування
cp .env.example .env          # Windows: copy .env.example .env
python -m app.cli gen-keys    # скопіюйте SECRET_KEY і FERNET_KEY у .env
```

Відкрийте `.env` у будь-якому текстовому редакторі та впишіть:
- `TELEGRAM_BOT_TOKEN` — токен бота від @BotFather;
- `SECRET_KEY` і `FERNET_KEY` — з попередньої команди;
- за бажанням `ANTHROPIC_API_KEY` і `SMTP_*` (див. нижче).

```bash
# 3. Створити вхід адвоката (попросить пароль і покаже QR-код для 2FA)
python -m app.cli create-lawyer advokat

# 4. Запуск (бот + платформа)
python -m app.main
```

Відкрийте http://localhost:8000, увійдіть, у **Налаштуваннях** заповніть ПІБ і телефон адвоката.
Напишіть боту в Telegram `/start` — звернення з'явиться на дашборді.

> Бот працює, поки запущена команда `python -m app.main` і комп'ютер увімкнений. Для роботи 24/7 — VPS (нижче).

### Безпека токена бота

Токен дає повний контроль над ботом. Якщо він потрапляв у листування чи чат — у @BotFather виконайте
`/revoke`, виберіть бота і впишіть новий токен у `.env`. Файл `.env` нікому не пересилайте й не додавайте в git.

### Ключ Claude API (необов'язково)

Без ключа бот працює за анкетою: без уточнювальних питань, перевірки читабельності фото і з простою карткою
справи (відповіді клієнта по порядку). Щоб увімкнути ШІ:
1. Зареєструйтесь на [console.anthropic.com](https://console.anthropic.com), поповніть баланс (від 5 $).
2. **API Keys → Create Key**, скопіюйте ключ у `ANTHROPIC_API_KEY` у `.env`, перезапустіть програму.

Модель задається `CLAUDE_MODEL`. За замовчуванням `claude-opus-5-5` (найякісніша).
`claude-haiku-5-5` приблизно в 40 разів дешевша — можна перемкнути одним рядком, якщо витрати завеликі.
Увімкнено резервний механізм Anthropic: якщо модель відмовить через фільтри безпеки, запит автоматично
повториться на іншій моделі.

### Email-сповіщення (необов'язково)

Для Gmail: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, `SMTP_USER` — ваша пошта, `SMTP_PASSWORD` —
**пароль застосунку** (Google Акаунт → Безпека → Двоетапна перевірка → Паролі застосунків), `LAWYER_EMAIL` —
куди надсилати. Без цього сповіщення видно лише на дашборді.

## Імпорт наявної бази з Excel

**Клієнти → шаблон** — завантажте `.xlsx`, перенесіть туди клієнтів і опонентів (колонки: ПІБ/назва, тип,
телефон, РНОКПП/ЄДРПОУ, роль, справа, примітка) і завантажте назад. Дублікати пропускаються.
Імпортовані записи одразу беруть участь у перевірці конфліктів.
Експорт: кнопки **«Експорт в Excel»** (клієнти) і **«Звернення в Excel»**.

Можна й з командного рядка: `python -m app.cli import-excel база.xlsx`.

## Де зберігаються дані

Усе — у папці `data/`: `data/app.db` (база SQLite) і `data/files/` (документи клієнтів).
**Резервна копія** = скопіювати папку `data/` **і** файл `.env` (без `FERNET_KEY` коди не розшифруються).
Зберігайте копії лише в захищеному місці.

## Перенесення на сервер (VPS)

Підійде будь-який VPS у ЄС (~5 $/міс, напр. Hetzner CX22) з Docker.

```bash
git clone https://github.com/Fabicool/lawtgbot.git && cd lawtgbot
cp .env.example .env   # заповнити; BASE_URL=https://ваш-домен, COOKIE_SECURE=true
docker compose up -d --build
docker compose run --rm app python -m app.cli create-lawyer advokat
```

Платформа слухає лише `127.0.0.1:8000`. Назовні її відкривають через HTTPS, наприклад
[Caddy](https://caddyserver.com) з одним рядком конфігурації: `ваш-домен { reverse_proxy 127.0.0.1:8000 }`.
Перенести дані з комп'ютера — скопіювати `data/` і `.env` на сервер.

## Для розробника

```bash
pip install -e ".[dev]"
pytest          # тести (Telegram і Claude підмінені — мережа не потрібна)
ruff check app tests && ruff format --check app tests
```

Структура:
- `app/channels/telegram/` — бот: `intake.py` (Приймальник, кроки зберігаються в базі), `bot.py`, `sender.py`
- `app/messaging/hub.py` — єдиний модуль повідомлень (сюди згодом підключаються Viber/WhatsApp)
- `app/agents/` — Claude: `analyst.py` (картка справи), `intake_agent.py` (терміновість, уточнення, документи)
- `app/core/` — статуси, конфлікти, маскування, шифрування, Excel, налаштування, email
- `app/web/` — платформа адвоката (FastAPI + Jinja2)
